# `old_firmware_fw0.hex`

A **fixed, checked-in** snapshot of a full ATtiny1616 flash image (I2C
bootloader at `0x0000` + offset application at `0x0800`) built with
`FW_VERSION` forced to `0` -- i.e. a stand-in for "a board already in the
field, running an old application, that already has the bootloader
installed."

This is what the production jig's `TEST_FW_BOOTSTRAP` step UPDI-flashes onto
the DUT as its *starting* state, so the following `TEST_FW_I2C_UPDATE` step can
exercise ["enter bootloader from a running app"](../../../BOOTLOADER_NEXT.md)
over I2C and update it to the current application in-band, the same way a real
in-field update would work. It is a **one-off build, not regenerated by any
build hook** -- unlike `include/fader_app_image.h` (the *current* application
image), which the `pre_embed_app_image.py` pre-build hook regenerates on every
jig build.

Only rebuild/replace this file if you deliberately want to change the fixed
"old" starting state (e.g. the bootloader's own format changes in a way that
breaks compatibility with old app images). Ordinary application changes
should NOT touch this file -- the whole point is that it stays fixed so the
test keeps exercising a real old-to-new transition.

## How it was generated

```bash
source ~/.platformio/penv/bin/activate
cd /home/scott/src/motorFader   # repo root, where the root platformio.ini lives

# Build the bootloader and an app forced to FW_VERSION=0 in one pass (building
# them together in a single `pio run` avoids each env's build directory being
# reaped between separate invocations).
PLATFORMIO_BUILD_FLAGS="-DFW_VERSION=0" pio run -e fb_bootloader_only -e fb_app_only

python3 - <<'EOF'
from intelhex import IntelHex

bl = IntelHex(".pio/build/fb_bootloader_only/firmware.hex")
app = IntelHex(".pio/build/fb_app_only/firmware.hex")
assert bl.maxaddr() < app.minaddr()  # disjoint regions, no overlap

merged = IntelHex()
merged.merge(bl, overlap='error')
merged.merge(app, overlap='error')
merged.write_hex_file("production_tools/programAndTest/factory_test_images/old_firmware_fw0.hex")
EOF
```

`FW_VERSION=0` is baked in via the `#ifndef FW_VERSION` guard in
`firmware/src/shared/i2c_data.h`, which otherwise defaults to the real
current version. The jig firmware's `OLD_FW_VERSION_FOR_TEST` constant
(`production_tools/programAndTest/src/main.cpp`) must match whatever value is
used here.

Flashed via `firmware/tools/flash_with_fuses.py` (same tool the
`fb_app_and_bootloader` PlatformIO env uses) with `--erase --bootend 0x08
--append 0x00`, invoked directly by `test_host.py` rather than through a
PlatformIO environment.
